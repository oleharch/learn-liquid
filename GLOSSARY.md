# Глосарій — як називати речі

Принцип: **терміни — як у документації Shopify і Liquid, латиницею; речення —
українське.** Ми не перекладаємо буквально те, що професіонали кажуть
англійською. Мета: те, що читач прочитає тут, він зможе сказати на созвоні —
і його зрозуміють. Буквальний переклад («область видимості», «макет»,
«метаполе», «застарілий») — помилка контенту, її ловить `pnpm lint:terms`.

## Правила написання

1. **Термін-поняття — латиницею, без бектиків, не відмінюється:** «у scope
   сніпета», «це output тегу», «layout теми», «фільтр deprecated».
2. **Ідентифікатор коду — у бектиках:** `product.title`, `{% render %}`,
   `cart.item_count`. Обʼєкт як поняття — латиницею без бектиків: «product має
   три варіанти», «додати product до cart», «customer увійшов».
3. **Дієслова — українські:** рендерити, виводити, ескейпити, дебажити,
   пагінувати, підключати. Не «друкує» (це калька з print).
4. **Латиницю не відмінюємо і не ставимо в множину.** Будуємо речення так, щоб
   не треба було: «кожен product у collection», «усі line items у cart»,
   «варіанти product» (варіант — усталене українське).
5. **Текст, який бачить покупець магазину, — українською.** Кнопки й підписи
   всередині шаблонів прикладів («Додати в кошик», «Товар недоступний»,
   «Ваш кошик порожній») — це UI магазину, а не терміни. Лінтер їх не чіпає:
   він дивиться лише в прозу, а не в `template` / `code` / `solution`.
6. **Перша згадка складного терміна на сторінці — з поясненням у дужках,
   один раз:** «scope (область видимості)». Далі — лише термін. Лінтер
   пропускає дужки, що стоять одразу після латинського терміна, — тож тут
   буквальний переклад легальний, а деінде ні.
7. Назви розділів сайту (Курс, Довідник, Shopify, Пісочниця, Співбесіда,
   Шпаргалка) — українські. Це навігація, не терміни.

## Обовʼязкові заміни — лінтер вважає помилкою

| Було | Стало | Приклад |
|---|---|---|
| вивід, у виводі, друкує, надрукований | **output**; дієслово «виводить» / «рендерить» | «`{{ }}` виводить значення в output» (іменник «друк» — print, «версія для друку» — легальний) |
| область видимості | **scope** | «`render` створює ізольований scope» |
| керування пробілами, пробільні символи | **whitespace control**, **whitespace** | «дефіс у тегу — це whitespace control» |
| налагодження, налагоджувати | **debugging**, дебажити | «для debugging є фільтр `json`» |
| продуктивність | **performance** | «performance теми» |
| макет | **layout** | «`layout/theme.liquid`», «layout теми» |
| застарілий, застаріло | **deprecated** | «`img_url` deprecated, бери `image_url`» |
| метаполе | **metafield** | «metafield з type `list.single_line_text_field`» |
| метаобʼєкт | **metaobject** | «metaobject типу `brand`» |
| налаштування теми | **theme settings** | «theme settings живуть у `settings_schema.json`» |
| посторінковий, пагінація (іменник) | **pagination** | «pagination через `{% paginate %}`» |

## На розсуд — лінтер попереджає, автор вирішує

| Слово | Коли міняти | На що |
|---|---|---|
| товар | коли йдеться про обʼєкт/дані (`product`, картка, властивості) | **product** |
| кошик | коли про обʼєкт `cart` і його дані | **cart** |
| клієнт, покупець | коли про обʼєкт `customer` | **customer** |
| позиція (кошика) | завжди, коли про `line_item` | **line item** |
| рядок | коли це тип даних string; «рядок коду», «у третьому рядку» — лишається | **string** |
| ресурс | коли про папку `assets/` і файли теми; «ресурс за handle» (resource) — лишається | **assets** |
| дробове число, ціле число | коли важливий тип | **float**, **integer** |

Українське слово лишається, коли йдеться про річ у реальному світі: «товар на
полиці», «покупець бачить кнопку», «кошик у шапці сайту» — і завжди в текстах
UI магазину всередині шаблонів.

## Лишаємо українською — усталене

тег, фільтр, обʼєкт, властивість, масив, число, змінна, цикл, умова, сніпет,
секція, блок, схема, пресет, рендер, екранування (можна «ескейпити»), колекція,
варіант, вендор, переклади, розмітка, обгортка, лічильник, діапазон (для
`(1..5)` можна range), ланцюжок фільтрів, пастка, підказка, еталон, шаблон
(коли це Liquid-код узагалі: «шаблон рендериться»; але папка `templates/` і
JSON template — латиницею).

## Терміни Shopify — як у shopify.dev

layout · template (JSON template, Liquid template) · section · section group ·
block · app block · snippet · asset · locale · schema · preset · theme settings ·
`settings_schema.json` · metafield · metaobject · handle · Drop · line item ·
variant · vendor · checkout · deprecated · Theme Editor (можна «редактор теми»)
· Online Store 2.0 · Liquid drop.

## Типи даних

string · number (integer / float) · boolean · nil · array · object · EmptyDrop
· range. Українською можна: масив, число, обʼєкт. Не можна: «рядок» для string
— плутається з рядком коду.

## Перевірка

```
pnpm lint:terms                              # увесь контент
pnpm lint:terms src/content/docs/tags.ts     # свій файл
```

Помилки (таблиця «Обовʼязкові заміни») мають бути нулем. Попередження — кожне
переглянути й або виправити, або свідомо лишити (річ у реальному світі, UI
магазину, рядок коду).
